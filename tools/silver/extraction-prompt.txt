Extract only explicitly stated scalar synthesis and measured structure facts from this local paper text. Return one JSON object with the supplied draft metadata and a claims array. This is an unreviewed machine extraction. Do not read another extraction. Do not infer facts, calculate particle sizes from spectra, read plot pixels, or fill a recipe using another paper.

Each claim must contain recipe_id, sample_id, slot_id, field, value, unit, value_text, unit_text, document_id, page, quote, link_quote, link_page, modality, technique, chemical_id. Use literal recipe/sample labels in the source, not invented UUIDs. Recipe-level quantities may set sample_id to null. Structure fields require an explicit non-null sample/product label. slot_id is a short stable field/context identifier (e.g. precursor-cobalt-acetate-amount, growth-temperature, sample-A-diameter). Different conditions or samples must have separate claims and recipe/sample IDs.

Allowed fields: reaction_temperature, duration, precursor_amount, solvent_volume, concentration, particle_diameter, core_diameter, shell_thickness, hydrodynamic_diameter, crystallite_size, phase, morphology, precursor_identity. Numeric values are one scalar number; do not extract ranges or approximate values into a scalar without marking them (unsupported in this pilot: omit the claim). phase, morphology and precursor_identity are exact source text strings; unit is null for these. value_text must be the exact source spelling of the value. unit_text must equal unit and appear exactly in the quote. Allowed units: °C, K, s, min, h, d, mol, mmol, µmol, g, mg, L, mL, µL, mol/L, M, mM, nm, µm, Å. Preserve source units: never relabel kelvin as °C or convert while extracting. No value is better than a guessed value.

quote must be a short contiguous verbatim span on the stated one-based PDF page that includes the value and unit in its experimental context. Do not paraphrase, add ellipses, or join text from different pages. link_quote and link_page must identify the literal recipe label, and for structure fields explicitly link that recipe to the product/sample label. A quote containing both labels is necessary but the automated validator does not understand causality: reject language that merely compares unrelated samples. Do not claim the synthesis/structure sample match if it is not explicit.

modality is always explicit_text. For structural measurements technique must be explicit: TEM or SEM for particle/core diameter, shell thickness or morphology; DLS only for hydrodynamic_diameter; XRD only for crystallite_size; XRD, SAED or electron diffraction for phase. The exact technique token must appear in quote, or supply the optional technique_quote and technique_page containing that token in an exact source span. Never put hydrodynamic or Scherrer size in particle_diameter. Set technique null for recipe fields. precursor_identity requires an exact registry chemical_id provided with the task; otherwise omit that field instead of inventing an ID. Set chemical_id null for other fields.

No additional keys, explanation, markdown or quotes outside the JSON. Retain conflicts as separate source-described claims with distinct slots, not an averaged or preferred value. Output {"schema":"mattersyn-silver/0.1/draft", ... SUPPLIED METADATA ..., "claims":[...]}. Empty claims are allowed and do not count as a published paper.
